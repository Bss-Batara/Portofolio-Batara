# Batara Portfolio

Responsive Mining IoT & Engineering portfolio website built with HTML, CSS and JavaScript. Designed for GitHub Pages deployment.

## Files
- `index.html` - content and sections
- `style.css` - styling and responsive layout
- `script.js` - mobile navigation and footer year

## Deploy on GitHub Pages
1. Create a repository (e.g. `batara-portfolio`).
2. Upload all files to the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, `main`, `/ (root)`, and save.

External hero photograph is loaded from Unsplash; internet access is required for that image and Google Fonts.
